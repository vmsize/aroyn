# Security

This initial source publication has been exercised on restricted staging. Do not include credentials, user records, payload data, or production configuration values in issues or proposed changes.

To report a vulnerability privately, send a direct message to **septave** on Discord. Describe the affected component, how to reproduce the problem, and its potential impact. Do not post exploit details publicly before the maintainer has had time to review them. Never send real user records, tokens, or production credentials; use a redacted example instead.

If Discord does not allow you to send a direct message, first send **septave** a friend request and, after acceptance, send the report privately. If this is unavailable, do not disclose vulnerability details in a public issue. A public issue may request an alternative private contact without describing the vulnerability. This project does not promise a response time or a bounty. On 2026-10-02, the maintainer tested from a second account and confirmed that a friend request reaches septave. This is the maintainer's functional observation, not an independent guarantee of future availability. No second private contact has been selected. The public-issue fallback only requests a private contact; never use it for sensitive report details.
