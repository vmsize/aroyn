# Как пользоваться Aroyn

Главную страницу можно открыть без входа. Скриншот dashboard на ней содержит демонстрационные данные. Все разделы dashboard требуют авторизации. Нажмите **Open dashboard → Sign in with Discord**, затем откройте **Runtime**. После входа создайте ключ dashboard через меню аккаунта, если ключа ещё нет.

В существующей совместимой версии Veyra Hub откройте раздел **Session** и введите этот ключ. Вернитесь на страницу **Dashboard → Runtime**: там появятся состояние подключения и текущая телеметрия. Разделы Activity, Inventory и Stats показывают данные, когда они поступают от запущенного клиента.

Ключ dashboard нужно хранить как пароль. Не публикуйте его в переписке, скриншотах или задачах GitHub. Если соединение не появляется, проверьте, что клиент запущен, ключ введён верно, а адреса API и live Worker относятся к тому же развертыванию.

Aroyn — новое название того же проекта. Текущий Roblox-клиент пока называется Veyra Hub.

Меню аватарки → **Account data** позволяет выгрузить данные аккаунта или удалить аккаунт Aroyn. Для удаления нужны вход через Discord за последние 15 минут и точный ввод `DELETE`; все сессии и ключи Aroyn отзываются. Аккаунты Discord/Roblox не удаляются. История хранится 30 дней без обновления, снимки — 7 дней; очистка выполняется ежедневно. Подробности и ограничения — в [описании работы с данными](account-data.md).

Этот пакет исходников не содержит Roblox клиент и способ его публичной установки. Локальный просмотр сайта сам по себе не подключает живые данные. Для запуска собственной серверной части см. [настройку проекта](setup.md).

## Запуск обновлённого Aroyn Hub

На [главной](https://aroyn-staging.pages.dev/) нажми **Copy launch script**. Кнопка копирует команду; **View launch command** позволяет выделить её вручную. Запускай команду в уже используемой совместимой среде для Greedy Growers. Эта инструкция не устанавливает и не рекомендует executor. После запуска ключ дашборда подключается в **Session**. Если он сохранён от предыдущего тестового клиента, Aroyn прочитает его автоматически.

[Страница состояния](https://aroyn-staging.pages.dev/status/) проверяет ответы двух HTTP endpoint. Панель владельца находится по `/admin/`; сервер выдаёт данные только аккаунту владельца. Доступ к дашборду по-прежнему ограничен приглашёнными участниками.
